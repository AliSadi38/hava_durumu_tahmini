# ⛅ Modern Hava Durumu Uygulaması

Bu proje, HTML, CSS ve JavaScript kullanılarak geliştirilmiş, kullanıcılara anlık hava durumu verilerini sunan ferah ve modern arayüzlü bir web uygulamasıdır. Canlı hava durumu verileri, Fetch API kullanılarak asenkron bir şekilde dış bir servisten çekilmekte ve DOM manipülasyonu ile ekrana yansıtılmaktadır.

## 📝 Proje Açıklaması
Uygulama açıldığında varsayılan olarak **Kocaeli** ilinin güncel hava durumunu gösterir. Kullanıcılar, arayüzdeki şık arama çubuğunu kullanarak istedikleri herhangi bir şehrin hava durumu bilgisine dinamik olarak ulaşabilirler. Proje, temiz kod yazımı (HTML, CSS ve JS dosyalarının ayrılması) ve asenkron JavaScript (`async/await`) yapılarının pratik edilmesi amacıyla geliştirilmiştir.

## 🚀 Özellikler
* **Modern ve Ferah Tasarım (Clean UI):** Göz yormayan renkler ve yumuşak geçişler.
* **Varsayılan Konum:** Açılışta Kocaeli hava durumu verilerinin otomatik yüklenmesi.
* **Dinamik Arama:** Arama çubuğu üzerinden farklı şehirlerin hava durumunu anlık sorgulama.
* **Canlı Veri Çekme:** `fetch` API ile RESTful hava durumu servisi entegrasyonu.
* **Anlık Güncelleme:** Sayfa yenilenmeden DOM manipülasyonu ile sonuçların gösterilmesi.

## 🛠️ Kullanılan Teknolojiler
* **HTML5:** Sayfa iskeleti
* **CSS3:** Modern arayüz tasarımı ve animasyonlar
* **JavaScript (Vanilla):** Asenkron veri çekme ve DOM manipülasyonu
* **API:** OpenWeatherMap (veya kullanılan hava durumu API'si)
